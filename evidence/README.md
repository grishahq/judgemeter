# Reproducible evidence

All demo observations are **synthetic**, with no model API calls or accuracy labels. Model names `stable` and `variable` are illustrative sequence generators, not real judges. The experiment compares the same 12 fixed cases, six trials per case per judge, binary scores, threshold 0.5 and seed 42.

The baseline `stable` assigns all 0s to six cases and all 1s to six cases. The candidate `variable` assigns three 0s and three 1s per case and shuffles each sequence using Python random.Random(42). Therefore both have mean 0.5. Baseline pair agreement = 1; candidate = (3×2 + 3×2)/(6×5) = 0.4. Kappa = 1 versus -0.2. This is an exact constructed counterexample to “same mean implies same consistency,” not a measured improvement, a benchmark of real models, or evidence of correctness. No generalization or statistical significance is claimed. Flip counts depend on shuffled order; pair agreement does not.

## Reproduce

```sh
judgemeter demo --records-out examples/judgemeter/synthetic-records.json \
  --json evidence/demo-report.json --html evidence/demo-report.html --baseline stable --candidate variable
python evidence/verify_statistics.py --output evidence/statistics-check.json
pytest -q tests/judgemeter
pytest -q py/autoevals/test_values.py py/autoevals/test_json.py py/autoevals/test_serializable_data_class.py
# Optional evidence rendering tools, separate from runtime:
python -m pip install matplotlib playwright
python -m playwright install chromium
python evidence/render_evidence.py
```

- `demo-report.json/html`: raw records, formulas' outputs, descriptive comparison and policy result.
- `statistics-check.json`: independent statsmodels 0.15.0 Fleiss kappa cross-check, 21 tables, seeded 20261025. Independent implementation, not independently gathered data.
- `judgemeter-tests.txt`: hand-calculated, missing-data, validation and CLI tests.
- `upstream-offline-tests.txt`: retained scorer/JSON/serialization tests.
- `upstream-tests.txt`: original broader attempt, 9 passed / 1 failed because test_partial calls a live judge and no model credentials were configured. Not counted as passing.
- `../campaign/assets/real-report-screenshot.png`: actual rendered HTML report, generated by the software.
- `../campaign/assets/demo-consistency-chart.png`: matplotlib chart calculated from demo-report.json, with synthetic-data disclosure.

## Review

An isolated verification agent authored and ran the 55-test contract suite and 21-table statsmodels check independently of the analyzer implementation. It identified numeric overflow validation, strict JSON identity and ambiguous trial gap semantics; these were corrected before release. Cyclic identity input is also normalized to ValueError. This review is a correctness review, not a full security audit.
